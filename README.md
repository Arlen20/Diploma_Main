# 📱 Fitness & Nutrition App (Flutter)

A cross-platform **fitness and nutrition mobile application** built with Flutter.
The app helps users manage their health routine by combining **workout planning, meal tracking, and progress analytics** in one place.

---

## 🚀 Download APK

👉 [Download APK](./app-release.apk)

> You can install the APK on your Android device and test the application.

---

## 🧩 Features

### 🔐 Authentication

* Email/password registration and login
* Email verification
* Password reset
* Protected routes (only authorized users can access main features)

### 🧍 Onboarding

Users provide:

* Fitness goal (lose weight / maintain / gain muscle)
* Height, weight, age
* Gender
* Activity level
* Training days per week

This data is used to personalize the experience.

---

### 🏋️ Workout Planning

* Automatically generated weekly workout plan
* Based on user goals and activity level
* Includes:

  * Exercises
  * Sets / reps or timers
  * Rest time
  * Instructions
  * Video demonstrations

---

### ▶️ Training Session Player

* Step-by-step workout execution
* Exercise video playback
* Timers for exercises and rest
* Session progress tracking
* Completion saved to database

---

### 🍽 Nutrition Tracking

* Add meals manually
* Simulated AI-based nutrition analysis:

  * Calories
  * Protein
  * Carbohydrates
  * Fat

---

### 📊 Statistics

* Total meals
* Average calories
* Total protein / carbs / fat
* Meal history overview

---

### 🏠 Dashboard

* Daily summary
* Today's workout
* Latest meal
* Quick navigation

---

### ⚙️ Profile & Settings

* Edit personal data
* Update fitness goals
* Avatar upload
* Logout / reset password

---

## 🛠 Tech Stack

* **Flutter** – UI framework
* **Firebase Authentication** – user authentication
* **Cloud Firestore** – database
* **Riverpod** – state management
* **GoRouter** – navigation and route protection
* **Video Player** – exercise demonstrations
* **Image Picker** – avatar upload

---

## 🏗 Architecture

* Feature-based structure
* Separation of UI, state, and data layers
* Firebase as backend
* Riverpod for scalable state management
* GoRouter for protected navigation

---

## 💡 Key Highlights

* Secure authentication flow
* Persistent user data in Firestore
* Personalized workout generation
* Real app logic (not just UI)
* Clean and scalable architecture
* Interactive training sessions with video
